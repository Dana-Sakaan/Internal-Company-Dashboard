# Internal-Company-Dashboard
A full-stack client request management system built with React, Tailwind CSS, Node.js, Express, and MySQL. Clients can submit requests, while admins can view requests in a dashboard and update their status through a responsive interface.

#Log In Form

Mock Login
The application includes a mock login form with frontend credential verification. Only users with the predefined credentials can access the dashboard.

#Create Client Request Form

A new request can be submited by providing the client name. The request is sent to the backend and stored in the database with a default status of New.

#Requests Dashboard

The dashboard retrieves client requests from the backend and displays them in a table along with their current status. Administrators can update a request's status directly from the dashboard, with changes sent to the backend and stored in the MySQL database.
